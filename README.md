# Консольное приложение для аналитики заказов (Python + PostgreSQL)

Скрипт автоматизации учета и финансовой аналитики, работающий напрямую с СУБД PostgreSQL.

## Функционал
* Интерактивное консольное меню для управления данными
* Добавление новых заказов в базу данных
* Сортировка заказов по стоимости (ORDER BY DESC) в реальном времени
* Финансовая аналитика (SUM, AVG, COUNT) силами самой базы данных

## Стек технологий
- Python 3
- PostgreSQL
- Psycopg2-binary
